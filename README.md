# Projeto Genius (Arduino)

Recriação do clássico jogo de memória **Genius** em um Arduino simulado no
Tinkercad — o jogo emite uma sequência de cores/sons que aumenta a cada
rodada, e o jogador precisa repeti-la corretamente.

![Projeto Genius](https://github.com/MasterySuporte/Projeto-Arduino---Genius/assets/84245534/dffc71db-ffac-45f7-8137-a7dc07359dc7)

## Tecnologias

- C/C++ (Arduino)
- Simulação em [Tinkercad Circuits](https://www.tinkercad.com/things/iHxnpHBVPDn-projeto-genius-lip/editel)

## Arquivos

- `main.c` — lógica do jogo (leitura de botões, sequência e verificação)
- `Projeto Genius- LIP.brd` — esquema do circuito

## Como rodar

Abra o link do Tinkercad acima para simular direto no navegador, sem
precisar de hardware físico.
